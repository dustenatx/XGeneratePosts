# Author Profile — scaffold

Copy this file to your data directory (default `~/XPosts/author_profile.md`)
and rewrite it in your own words. It never belongs in the repo: it is your
voice, and for most people it contains details they would not publish as a
config file.

The script parses `##` headings. **Beat** and **Voice** are required; the rest
are optional but each one measurably improves the output. Headings the script
does not recognize are ignored, so you can keep notes to yourself in here.

Write in plain prose and short bullets. You are briefing a sharp new
ghostwriter who has never met you — not filling in a form.

Delete everything above this line once you have read it.

Guardrail — keep this, it does real work:

- Reference AT MOST ONE of the above per post, and only when it directly
  illuminates the item — never as a credential flex.
- NEVER invent experience, metrics, employers, clients, tools, or anecdotes
  beyond this list. If none fits, write the post without any.

## Never

*Hard rules. What would embarrass you or misrepresent you?*

Anything here is worth being explicit about, because the model will otherwise
guess. Common entries:

- Never name my employer or clients.
- Never state or imply years of experience, career length, or "back when".
- Never claim hands-on depth with tools I have not used — opinions are fine,
  implied operational history is not.
- Never inflate my title, level, or scope.
- Never disparage a named company; critique the pattern instead.
